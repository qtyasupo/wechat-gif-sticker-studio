# 尺寸与用途参考

这是本工作流的可修改配置，不是永久官方规则。上传页截图和当前入口要求优先。机器可读配置：[wechat-profile.json](wechat-profile.json)。

| 用途 | 交付尺寸 | 格式与背景 | 检查重点 |
| --- | --- | --- | --- |
| 统一静态造型参考 | 512×512 | PNG；按选择纯白或真实透明 | 单角色、无台词、完整耳朵和四肢，约8%安全边距；用户确认 |
| 静态高清原稿 | 建议1024×1024或以上 | 原始PNG | 保留另存，不将生成目标当实际输出尺寸 |
| 网页GIF创作目标 | 512×512、约2秒循环 | GIF；透明需实际核验 | 与上传规格分开；实际输出由入口决定 |
| 像素风方法参考 | 上游常见320×320 | GIF | 仅在用户选像素风时借鉴 |
| 上传GIF副本 | 240×240 | GIF，保留实际背景属性 | 等比缩放补边，保留循环和时长，原文件不变 |
| 单张缩略图 | 120×120 | PNG | 对应GIF的代表首帧 |
| 专辑横幅 | 750×400 | PNG；允许时另附JPEG | 默认无文字，横构图完整，无拉伸 |
| 专辑封面 | 240×240 | 透明PNG | 单一完整主体、无文字，alpha含透明和不透明像素 |
| 聊天图标 | 50×50 | 透明PNG | 单独头部近景，真实尺寸仍能辨认 |
| 赞赏引导 | 750×560 | PNG；允许时另附JPEG | 标题准确、温和自愿，构图留边 |
| 赞赏致谢 | 750×750 | PNG；允许时另附JPEG | 感谢文案准确，不遮挡角色 |

字数工作配置：名称1–8、介绍1–80、版权1–10、赞赏语5–15个可见字符，标点也计数。最终以页面计数器为准。体积上限尚未确认时，只报告实际字节数；确认限制后更新profile对应max_bytes。

先用内置图像工具生成造型，查看图片，再读取尺寸和alpha。用现有机械导出器输出新文件：

```bash
python scripts/sticker_pack.py resize-asset --input reference-master.png --output reference.png --width 512 --height 512
```

该命令需要FFmpeg，默认等比补透明边。照片或白底图的原背景仍保留；透明补边不等于去底。完整主体应在生成时留好安全边距。白底参考也可在机械图像处理环节等比补白。

导出后用Pillow读取 `Image.open('reference.png').size`，应为 `(512, 512)`；需透明时检查A通道既有0也有255。用实际导出图请用户确认。尺寸检查不判断身份是否一致。
