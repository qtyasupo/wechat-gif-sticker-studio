# Image 2.6 网页端 GIF 表情包提示词

每次复制一条完整提示词，生成一张独立的动态表情包。在网页端提供 GIF 或动画选项时，同时选择相应选项；提示词里的尺寸与时长是创作要求，实际输出取决于网页端提供的功能。

以下默认使用统一的Q版橘猫：圆脸、橘色条纹、奶油白嘴套和肚皮、小三角耳、短爪、粗尾巴、薄荷绿小领巾，简洁清晰的二维卡通风。可以把每条中的橘猫设定换成自己的角色，或上传参考图并增加：「严格沿用参考图中的角色外貌、服装、配色和标志性配饰。」

默认使用纯白背景，便于聊天展示；纯白背景不等于透明背景。以下不承诺网页端支持透明GIF。

## 生成后可直接追加的修改提示词

### 文字出错

```text
保留当前GIF中的角色外貌、构图和动作，仅修正底部文字为「收到」。准确使用这两个简体中文字，不增删、不重复、不使用近似字。文字在全部帧中保持同样的字形、大小和位置。如果当前入口不能编辑GIF，请基于上述要求重新生成完整GIF。
```

### 动作只有整图摇晃

```text
重新生成GIF。保持角色设定和画风，重点让角色右手臂完成抬起、敬礼、放下的动作，头部配合轻轻点头。躯干位置与背景稳定。需要真实的局部姿势变化，不要把整张静态图片当成一个整体旋转、拉伸或上下移动。首尾回到相近的自然站姿，连续循环。
```

### 首尾衔接突兀

```text
重新生成同一角色、同一画风、同一主题的GIF，调整动作顺序，让动作在结尾自然返回开头的姿势、位置、视线和道具状态，特效在循环末尾消失。不靠突然切画面或淡入淡出掩盖跳变，保留动作的准备、执行和回位过程。
```

### 统一同一套角色

```text
以我提供的这张角色图为统一设定，保持脸型、眼睛、毛色分区、身体比例、领巾颜色、轮廓线粗细和画风。下一张只改变主题、表情、动作与必要道具。继续使用同样的纯白背景、角色占画面比例，以及底部文字的字体、位置和大小，生成单张完整GIF。
```
